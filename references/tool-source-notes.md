# Verified source notes for the tool-selection guide

Reviewed official pages on 2026-11-05. These notes verify a sample of category roles, not every listed tool or current licensing/pricing detail. Always check each selected product's current official documentation, pricing, service terms, and item-level license before use.

- Radix Colors describes UI color scales, semantic use cases, accessible text/background pairings, dark mode, transparent variants, APCA, and P3 support: https://www.radix-ui.com/colors
- Adobe Leonardo describes color-system and visualization tools, contrast-based color generation, color spaces, themes, scales, and design-token outputs: https://leonardocolor.io/
- Mobbin describes a searchable library of real mobile/web screens, product flows, and UI patterns. Its own guidance says references show what shipped, not proof of user outcomes; it directs agents to compare examples and distinguish observation from inference: https://mobbin.com/
- Page Flows describes recorded/annotated user flows for onboarding, login, checkout, search, and related tasks: https://pageflows.com/
- Refero describes screens, flows, patterns, and research mode: https://refero.design/
- Awwwards and Godly curate websites and design inspiration. These are useful for visual discovery, not evidence that a pattern is usable or accessible: https://www.awwwards.com/ and https://godly.website/
- Google Fonts exposes font discovery plus guidance on readability, language, web-font use, loading, and self-hosting: https://fonts.google.com/
- Fontshare exposes font families/filters and links to its license information; verify the exact family and terms: https://www.fontshare.com/
- Fontsource describes downloading and self-hosting font files through packages/CSS/CDN. Verify each font's license and language coverage: https://fontsource.org/
- Fontjoy generates suggested type combinations. Treat generated pairings as starting options that require human/context review: https://fontjoy.com/
- shadcn/ui documents a component catalog and theming/registry workflows: https://ui.shadcn.com/docs/components
- Base UI describes unstyled React components intended for accessible interface construction: https://base-ui.com/
- Radix Primitives describes unstyled React primitives with keyboard/focus/accessibility behavior: https://www.radix-ui.com/primitives
- Magic UI describes animated React/TypeScript/Tailwind/Motion components. Verify the exact item license and dependency: https://magicui.design/
- Aceternity describes React/Tailwind/Motion components, blocks, templates, and registry/agent workflows; free/paid scope differs: https://ui.aceternity.com/
- Motion describes JavaScript/React/Vue animation capabilities including layout, gestures, scroll, and performance guidance: https://motion.dev/
- GSAP describes JavaScript animation for UI, SVG, and WebGL: https://gsap.com/
- Rive describes an editor/runtime and interactive motion workflows across platforms: https://rive.app/
- Three.js identifies itself as a JavaScript 3D library and provides documentation/examples: https://threejs.org/ and https://threejs.org/docs/
- React Three Fiber describes itself as a React renderer for Three.js: https://r3f.docs.pmnd.rs/
- Lucide documents a consistent, customizable SVG icon family and its license page: https://lucide.dev/
- Playwright Test is an end-to-end browser test framework: https://playwright.dev/docs/intro
- Playwright's accessibility testing guide explicitly says automated scans find some issues only and recommends combining automation, manual assessment, and inclusive user testing: https://playwright.dev/docs/accessibility-testing
- Official Storybook accessibility-testing docs: https://storybook.js.org/docs/writing-tests/accessibility-testing
- axe-core project: https://github.com/dequelabs/axe-core

The following user-named assets/services are useful discovery sources, but this document does not verify current offerings, prices, licenses, or availability for each one: Huetone, Typewolf, Fontshare, Mobbin, Godly, Awwwards, Refero, 21st.dev, Tabler, Phosphor, unDraw, DrawKit, Unsplash, and Pexels. Check source documentation and exact asset terms before adopting anything.
