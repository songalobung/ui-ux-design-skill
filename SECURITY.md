# Security policy

## Scope

This repository contains Markdown instructions, templates, and reference links for AI-assisted UI/UX work. It does not contain a deployed application, authentication service, or executable product code. Reports may concern a compromised repository or link, unsafe or misleading security guidance, prompt-injection content in a bundled source, or another issue that could create a security or privacy risk when the material is used.

## Reporting a concern

Please do not publish exploit details, credentials, private data, or other sensitive information in a public issue or discussion.

Use GitHub’s **Report a vulnerability** option on this repository’s Security tab when it is available. If private vulnerability reporting is unavailable, contact the repository owner privately through the GitHub profile [@songalobung](https://github.com/songalobung) and ask for a private reporting channel. Include the affected file or commit, the potential impact, and enough detail to reproduce the issue safely. Redact secrets and personal information.

The maintainer will review reports and coordinate a fix or clarification where appropriate. This repository does not promise a specific response or remediation timeline.

## Supported version

The latest revision on the default branch is the supported version. Older commits are provided for history and may contain issues that have since been corrected.
